# Desktop — browser and Home Assistant

These exist in the **Windows and Linux apps**, not in the website tab.

## Embedded browser

Open the browser icon in the top bar (if shown). Chat can navigate, read the page, click, and fill fields when those tools are listed. Useful for “open this site and summarize it” on the desktop.

## Home Assistant

Open **Home Assistant** in the settings icons. Enter your HA URL and a long-lived token. When configured, chat can list and control entities (lights, media, services).

Tokens stay on this device.

## Setup wizard

Settings → **Run setup wizard** can install a Home Server (local login site), Lemonade, and/or Ollama on this PC.
