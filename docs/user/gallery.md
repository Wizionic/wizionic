# Gallery

Albums and images live on this device. Image bytes are encrypted at rest.

## Basics

- Create albums and save images from chat (for example after Lemonade generates one).
- You can protect an album with your account password the same way as a notebook.
- Sync copies albums you choose to other signed-in devices.

## Chat

Prefer `generation_id` from an image that was just created. Do not ask the model to “also save” every image unless you want it in the gallery.
