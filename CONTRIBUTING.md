# Contributing

This repository is public so people can inspect Wizionic, verify the privacy model, and fork it.

**I am not seeking contributors.** Unsolicited pull requests — including feature work, drive-by refactors, dependency bumps, and “I asked an AI to improve this” patches — will be closed.

## Forks

If you want a different product, **fork the repo** and keep your fork. That is the intended path for major modifications.

## Issues

Open an issue only for:

- A confirmed bug you can reproduce on the latest [GitHub Release](https://github.com/Wizionic/wizionic/releases/latest)
- A security problem (prefer the private process in [SECURITY.md](SECURITY.md))

Feature requests and “would be nice” issues may be closed without comment.

If I want a specific fix from someone, I will open the issue myself or ask directly.

## Support

Best-effort only. There is no SLA.
