# Contributing to Wizionic

Thank you for your interest in Wizionic!

Wizionic is open source to ensure **transparency** and **trust**. By making the code public, anyone can verify our privacy model, audit our security, and see exactly how we handle (or don't handle) user data.

## Current Development Model

Wizionic is currently being built and maintained by a single developer. To ensure rapid iteration, high code quality, and strict alignment with the product vision, **we are not accepting unsolicited pull requests for new features or code changes at this time.**

### What This Means

- **Pull Requests:** Please do not submit PRs for new features, refactors, or dependency updates. These will be closed without review to maintain the stability of the codebase.
  - *Exception:* Critical bug fixes or security patches.
- **Forks:** You are free to fork this repository for personal learning or to build your own variations. If you do fork:
  - Please respect the **Apache 2.0** license terms (attribution required).
  - Do not imply your fork is the official Wizionic product.
  - We encourage you to build *your own* unique projects rather than competing forks of this specific product while it is in early stages.

### Reporting Bugs & Vulnerabilities

We take security and stability seriously. Please follow these guidelines:

- **General Bugs:** If you find a reproducible bug in the latest release, please open a **GitHub Issue** with clear steps to reproduce.
- **Security Vulnerabilities:** **Do not** report security issues via public GitHub Issues.
  - Please use **GitHub Security Advisories** (private) or email `daniellgoodwin@protonmail.com`.
  - Include a description, impact, and steps to reproduce.
  - I aim to acknowledge reports within 7 days.
  - For more details, see our [Security Policy](SECURITY.md).

### How You Can Help

Even without code contributions, you can make a huge impact:
- **Star the repository:** Helps others discover the project.
- **Share Feedback:** We value your thoughts on features, UX, and privacy.
- **Spread the Word:** Tell friends or colleagues who might benefit from a privacy-first AI assistant.

## Future Opportunities

As the project grows, we may open up opportunities for community contributions, especially for documentation, testing, or specific community-requested features. Please watch this space for updates.

Thank you for respecting the development process and helping us build a secure, trustworthy product!
